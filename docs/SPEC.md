# Spec — odin-glib

## Packages

| package | surface |
|---|---|
| `glib` | every public declaration of `glib.h` |
| `gobject` | every public declaration of `glib-object.h`; `signal_connect`, `signal_connect_after`, `signal_connect_swapped`, `signal_handlers_disconnect_by_func`, `signal_handlers_disconnect_by_data`, `signal_handlers_block_by_func`, `signal_handlers_unblock_by_func`, `type_cast`, `type_is` |
| `gio` | every public declaration of `gio/gio.h`; `application_run`; a cast `FOO` and a check `IS_FOO` for every `TYPE_FOO` |

Import through the `glib` collection: `import "glib:<package>"`. `gobject` and `gio` import
`glib`; `gio` imports `gobject`.

## Naming

runic trims the `g`/`G` prefix and the library prefix: `g_file_new_for_path` is
`file_new_for_path`, `GApplicationFlags` is `ApplicationFlags`. Enum members keep their
group word (`ApplicationFlags.APPLICATION_NON_UNIQUE`). `gchar *` is `cstring`, a byte buffer
parameter (`data`, `buf`, `buffer`) is `^byte`. A fundamental type id is a constant (`TYPE_OBJECT`); a class type is the procedure
`TYPE_FOO` (`TYPE_APPLICATION`, an alias of `application_get_type`).
C-variadic procedures are bound with a trailing `#c_vararg var_args: ..any`; see
[Variadic procedures](#variadic-procedures).

## Flags

A GFlags type is a `bit_set` of its `FooBit` enum with the C size: `glib.SpawnFlags` is
`bit_set[SpawnFlagsBit; u32]`, written `{.SPAWN_SEARCH_PATH}`. The empty set is the C zero
member, as a constant (`glib.SPAWN_DEFAULT`) or `{}`; composites are constants
(`glib.TRAVERSE_ALL`). The full list and the naming rules are DECISIONS §8.

## Constants

`glib.TRUE` and `glib.FALSE` are untyped booleans, and `glib.SOURCE_REMOVE` and
`glib.SOURCE_CONTINUE` are `FALSE` and `TRUE`, so a `SourceFunc` returns them directly. An
error-domain macro is the quark procedure: `glib.FILE_ERROR()`.

## Signal handlers

`signal_handlers_disconnect_by_func(instance, func, data)`,
`signal_handlers_block_by_func` and `signal_handlers_unblock_by_func` take a typed procedure
and the closure data (default `nil`) and return the number of handlers matched, as the C
macros do. `signal_handlers_disconnect_by_data(instance, data)` matches by data alone.

## Casts

`gobj.type_cast(T, ptr, TYPE_T)` returns `^T`. It checks the instance's type when
`GTK_SAFE_CAST` is true (the default unless the build optimises for speed) and is a plain
pointer cast otherwise. `type_is` is `g_type_check_instance_is_a`.

A wrong cast does not abort: `g_type_check_instance_cast` logs a GLib critical and the
pointer is returned unchanged (a null instance is silent). Run with `G_DEBUG=fatal-criticals`
to make the critical abort.

`gobject/type_casts.odin` and `gio/type_casts.odin` are generated by `scripts/type-casts.sh`:
`FOO(ptr)` and `IS_FOO(ptr)`, as GObject's and GIO's C macros. `gobject` has `OBJECT`,
`INITIALLY_UNOWNED`, `BINDING`, `BINDING_GROUP`, `SIGNAL_GROUP`, `TYPE_MODULE` and
`TYPE_PLUGIN` (DECISIONS §12).

## Variadic procedures

runic writes a C `...` as `#c_vararg var_args: ..any`, which Odin passes as C variadic
arguments: 79 procedures (`object_new`, `object_get`, `signal_emit_by_name`, `signal_new`,
`error_new`, `strdup_printf`, `log`, `markup_collect_attributes`, …). Each argument is passed as its own C value, with the C default promotions
(`f32` as `double`, small integers and `bool` as `int`). Safe arguments are scalars of the
exact C type: `i32`, `u32`, `i64`, `f64`, `cstring`, `glib.boolean`, pointers, enums and
`nil` (a pointer; it ends a property list). An untyped integer literal is an Odin `int`
(64 bits) and an untyped float is `f64`: right for `gint64` and `gdouble`, wrong for a
`gdouble` given `1`. Never pass an Odin `string`, slice, array, struct or `any`: each is
split into several C arguments, which shifts every later one. Write `cstring("x")`, not `"x"`.
The binding does not check the arguments against the format string or the property types.

The 22 procedures that take a C `va_list` as their last parameter (`object_new_valist`,
`signal_emit_valist`, `strdup_vprintf`, `logv`, `vsnprintf`, …) are not bound: a `va_list`
cannot be built from Odin, and runic would bind them as `..any`, which passes the values
inline where C wants one `va_list`. Use the variadic form (`object_new`, `strdup_printf`,
`log`). DECISIONS §11 lists them; `make check-generated` fails if one comes back.

## `application_run`

`application_run(app: ^Application, args := os.args) -> i32` builds the C `argv` from `args`,
runs the application and frees the `argv` again.

## Deprecated API

Deprecated declarations are bound: generation sets `GLIB_DISABLE_DEPRECATION_WARNINGS`.

## Version

`GLIB_MAJOR_VERSION`, `GLIB_MINOR_VERSION` and `GLIB_MICRO_VERSION` are constants of package
`glib`, taken from the headers. The README records the bound version and `make test` compares
the two and the loaded library against it.
